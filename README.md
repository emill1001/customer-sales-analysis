# Customer Sales Analysis

# Business Scenario
A restaurant wants to better understand customer purchasing behaviour, loyalty, and spending patterns. SQL was used to analyze transactional data and generate insights that support marketing and customer retention strategies.

# Business Questions
- Which customers generated the most revenue?
- What was the average customer spending?
- Which menu item was purchased most frequently?
- How did the loyalty program affect customer purchases?
- Which products were most popular before and after joining the membership program?
- How many loyalty points did each customer earn?
